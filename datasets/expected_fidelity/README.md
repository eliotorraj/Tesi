# expected_fidelity

Questa cartella contiene i due scope del Dataset Qiskit diretto:

- `pilot`: 10 circuiti, split 6/2/2, 360 tentativi;
- `full`: 600 circuiti, split 422/88/90, 21.600 tentativi.

I manifest di split sono versionati. Circuiti copiati, JSONL e cache sono
rigenerabili seguendo `docs/qiskit_dataset.md`.
