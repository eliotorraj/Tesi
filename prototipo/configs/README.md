# Qiskit choice catalog

`qiskit_dataset_configurations_v2.json` defines five synthetic quantum Targets, twelve configurations and checked software versions. The LLM returns a `config_id`; the client resolves known compilation parameters without executing model-generated code.

The catalog describes quantum devices. Configure the host CPU/GPU separately; see [installation and runtime](../docs/installazione_e_runtime.md). Use the [toolkit](../../riproducibilita/configurazioni/README.md) to define a new search space and experiment. The selected prototype verifies the identity of its supplied catalog.
