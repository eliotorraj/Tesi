# Configurazioni Qiskit

Il catalogo JSON definisce le 12 configurazioni consentite e i cinque dispositivi sintetici del framework. Il programma usa i suoi identificativi per tradurre la scelta dell'LLM nei parametri di compilazione.

Le impronte dei Target e i vincoli di versione permettono di controllare la coerenza con i dati train. Le impostazioni di Qwen sono invece nel `config.json` della cartella principale. Per i controlli e il significato operativo vedere [architettura e flusso](../docs/architettura_e_flusso.md).
