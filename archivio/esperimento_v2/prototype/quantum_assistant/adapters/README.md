# Historical assistant adapters

`request.py` and `hardware.py` handle circuit constraints and Targets. `rag_dataset.py`, `rag_features.py`, `qdrant_context.py` and `rag_checks.py` load, transform and verify train retrieval. `context.py` builds evidence. `llm.py`, `validation.py` and `explanations.py` handle recommendations and checked explanations; `compilation.py` runs Qiskit. `parsing.py` preserves older import compatibility.

These implementations belong to the archived application and should be interpreted with its study and contract versions.
