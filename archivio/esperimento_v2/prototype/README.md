# Earlier assistant implementation

This is the historical application library, not the root-level standalone prototype. It prepares requests, filters devices, retrieves train examples, validates a recommendation and compiles after application-level confirmation.

`quantum_assistant/` contains services, types and adapters; `prompting/` contains prompt representations; `qdrant_dashboard/` supports optional inspection of a retrieval copy. The current public `app.py` workflow is documented under `prototipo/` at the repository root.
