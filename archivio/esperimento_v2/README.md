# Archived v2 experiment

This is the preserved experiment workspace based on Python 3.12 and MQT Predictor 2.4.0. Earlier status statements about unfinished validation or a closed Test describe historical stages, not the current repository. Completed later evaluations are indexed under `archivio/valutazione/`.

`configs/` defines the original experimental catalog; `datasets/` contains compiled aggregates and RAG examples; `artifacts/` contains attempts, models, manifests and LLM records. `prototype/`, `qiskit_dataset/`, `llm_selection/` and `scripts/` preserve the implementations. `tests/` contains their software checks. `docs/` preserves technical explanations and dated reports; `knowledge/` contains the primary local research sources; the nested `archivio/` holds earlier phases.

The local `pyproject.toml` and `uv.lock` document this environment. New installations and campaigns should follow the root-level toolkit guide.
