# Early expected-fidelity Dataset

`full/split_manifest.json` and `full/circuits/` are the original 600-circuit corpus references still checked by v2. `full/<device>/` contains earlier per-device outcomes. `pilot/` contains the reduced campaign and its comparisons.

The historical account is in `archivio/esperimento_v2/docs/resoconti/dataset_qiskit_v1.md`. Current operational rules are in the root-level toolkit guide. These stored measurements do not become outcomes of a new run merely by being copied.
