# Archived technical documentation

This directory preserves the experiment's historical protocol, implementation explanations, dated reports and maintenance records. `approfondimenti/` explains components; `resoconti/` records decisions and trials; `manutenzione/` records repository changes; `figure/` contains supporting illustrations. Research sources are in the sibling `knowledge/` directory.

`protocollo_sperimentale.md` here describes the archived workspace. The current scientific protocol is `prototipo/docs/protocollo_sperimentale.md` at the repository root; operational reproduction instructions are in the toolkit.
