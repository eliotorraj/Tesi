# Archived local LLM selection code

This package preserves the Qwen/Phi/Gemma selection workflow. Top-level study, controller, run, evaluation and report modules document the earlier v1 procedure. `v2/` implements the later facts/hypothesis study. `reports/` contains small readable extracts; full records are under the archived experiment's `artifacts/.../llm_selection/`.

Prompt/token audit modules examine representation; gateway, storage, weights and provenance modules manage execution evidence. PowerShell and `AmdSensors.cs` support the original Windows server and monitoring. Use the toolkit for new configurable studies. The archived setup requires its original data, model identity and machine-specific resources.
