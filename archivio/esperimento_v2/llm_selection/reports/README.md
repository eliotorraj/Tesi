# Small LLM audit extracts

`prompt_lossless_v2.json` records reconstruction and token checks for five train and 88 validation prompts. `qwen_prompt_v2_dj.json` summarizes the technical train DJ trial. `qwen_prompt_v2_dj_responses/` holds its unedited responses.

Checking 93 prepared inputs is not a completed validation study. The DJ responses passed JSON shape checks but failed evidence validation; these extracts preserve that unfavorable outcome.
