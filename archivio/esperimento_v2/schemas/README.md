# Archived JSON schemas

The schemas define assistant requests, hardware catalogs/masks, model response versions and saved compilation/method records. `llm_recommendation_v3.schema.json` and `llm_recommendation_v4.schema.json` belong to different prompt contracts. `qiskit_run`, configuration aggregates and RAG example schemas describe successive Dataset stages.

Schema validation detects shape/type errors; semantic checks also enforce catalog membership, device compatibility and evidence consistency. Select schemas by the recorded study version rather than treating every file as the current public response format.
