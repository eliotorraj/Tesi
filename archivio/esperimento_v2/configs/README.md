# Archived experiment settings

`qiskit_dataset_configurations_v2.json` defines five synthetic devices, twelve Qiskit configurations, three seeds, expected fidelity, software/Target identities, a 100-second attempt limit and six workers. `experiment_methods_v2.json` preserves the original method plan, including roles that were planned rather than completed.

Interpret executed studies using their own frozen contracts and outcome records. New configurable runs use `riproducibilita/configurazioni/` at the repository root.
