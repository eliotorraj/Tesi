# LLM study records

This directory stores evidence produced by the archived `llm_selection/` programs. `models/` and `runtime/` describe weights and server tools; `preparation/`, `profiles_to_freeze.json` and `frozen_study.json` describe setup and fixed conditions. `studies/` holds validation decisions, seals and reports. `analyses/` contains prompt/token audits; `technical/`, `technical_episodes/` and `technical_transport/` hold technical checks.

`controllers/`, `servers/`, `incidents/` and `storage_checks/` preserve execution and failure evidence. `manual_chats/` and `manual_examples/` are manual trials. `code_snapshots/` preserves the source revisions used. Consult `final_configuration.json` and `selection_complete.json` with the corresponding study rather than inferring completion from prepared prompts.
