# Execution logs

`rl/` contains per-device/run monitor CSV files, separate resume monitors and TensorBoard event files. `qiskit/` contains generation invocation metadata and logs. LLM records are in the sibling `llm_selection/` directory.

A started or nearly empty log establishes only that recording began. Check model metadata and completion records before treating training as complete. Keep interrupted and resumed segments distinct.
