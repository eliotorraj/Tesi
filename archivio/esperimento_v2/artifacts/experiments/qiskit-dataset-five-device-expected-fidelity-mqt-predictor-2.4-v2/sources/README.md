# Prepared circuit sources

`train/` contains the 422 train QASM records and `validation/` the 88 validation inputs prepared for the archived tools. Names and hashes are checked against the frozen manifest.

The original corpus remains in the nested protocol v1 archive. These copies preserve split assignments; their presence does not authorize moving circuits between train, validation and Test for a new result.
