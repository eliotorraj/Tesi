# Project archive

This directory preserves the experiments, sources and development records behind QAdviser. Use the reproduction toolkit for new campaigns and the standalone prototype for ordinary requests.

`esperimento_v2/` holds the earlier environment, original corpus, Dataset, validation studies and research sources. `valutazione/` holds subsequent training, Test campaigns, retrieval variants, oracle comparisons and checks.

Historical manifest paths are logical references resolved by the code; do not rewrite them to match the current directory layout. Current usage documentation is under `prototipo/docs/` and `riproducibilita/documentazione/` at the repository root.
