# MQT Bench report layout revision

This October 3 record documents adoption of the QASMBench report layout for the 90-circuit campaign. `precedente/` preserves the earlier generator, `resa/` and `resa_finale/` hold rendered pages, and `prima.json`/`verifica_finale.json` identify the checks.

The recorded revision verified six report tests, 360 incremental outcomes, 90 control outcomes and 16,200 oracle outcomes. Its final PDF has 20 pages and 20 separate figures. Layout changes retained the underlying data, signed gaps and denominators; these counts describe that report revision.
