# Development checks for k=1

`prima.json`, `derivazione.json` and `verifica_finale.json` document preparation and verification. `verifica_impaginazione.py` checks rendering. The October 3 record reports 40 checks across the two circuit collections: 15 procedure and five report checks per collection.

The tests simulate inference and compilation. They cover E1-only retrieval, fixed-memory isolation, independent order memories, resume/integrity, zero scores, missing data and use of the new k=1 control. They are separate from scientific outcomes.
