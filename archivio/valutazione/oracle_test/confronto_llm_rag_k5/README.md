# Five-example RAG versus Test oracle

`analizza.py` derives the comparison, `impagina.py` writes the report and `compila_verifica.py` checks compilation. `risultati/` contains `confronto_oracle_rag5.pdf` and `.tex`, a 90-circuit CSV, `dati.json`, standalone figures and provenance/verification records.

The comparison uses saved Manhattan RAG decisions with k=5 and the max3 oracle completed on September 29. It is a post-decision analysis, not a Dataset update or new model selection. Complete and partial oracle references, ties and denominators are retained in the data.
