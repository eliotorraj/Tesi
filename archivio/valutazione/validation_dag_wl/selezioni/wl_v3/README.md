# Frozen WL selection: h=24, k=5

`wl_h24.json` identifies the selected retrieval configuration; `analisi/` contains supporting selection analysis. The choice uses wl_v3 with 88 observable successful cases common to all 31 compared retrieval methods.

The historical criterion transfers the first pair from the first example, comparing coverage, mean regret and then median. h=24 is the smallest depth at the best observed mean-regret value shared with h=25–27. This frozen selection feeds the separate retrieval-only and DAG-summary Test variants. It does not change the original main Manhattan configuration or establish general performance outside the evaluated conditions.
