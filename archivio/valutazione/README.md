# Evaluation and experimental development

This area preserves completed comparisons and separate experimental extensions. New general-purpose campaigns belong in the reproduction toolkit. Some specialized historical launchers remain here with their original contracts.

`test/` holds the 90-circuit MQT Bench evaluation, random retrieval, example-count and WL extensions. `test_mqt_esplorativo/` contains the separately contracted MQT run with reduced Training set coverage. `test_qasmbench/` contains the 50-circuit external comparison. `oracle_test/` and `oracle_qasmbench/` provide exhaustive reference analyses. `validation_dag_wl/` records retrieval-depth selection.

`rag_incrementale/` contains separate fixed/incremental memory campaigns, including k=1 comparisons. `addestramento/` records MQT selector preparation; `verifiche_prototipo/` holds development checks. `documentazione_storica/` preserves earlier setup documentation. Read each campaign's plan and report for its actual status and conditions.
