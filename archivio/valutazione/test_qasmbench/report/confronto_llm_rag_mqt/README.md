# QAdviser and MQT on QASMBench

`confronto_qasmbench.pdf` and `.tex` contain the saved 12-page comparison with six figures. `dati/circuiti.csv` contains 100 method/circuit outcomes, including two timeouts; `dati/coppie.csv` contains the 48 common successes. `dati/riepilogo.json` records summaries and provenance.

`dati.py` and `genera_report.py` build the analysis; `compila.py` compiles it; `audit.py` checks it. `artefatti.json`, regeneration records and `anteprime/` preserve verification. Only September 30 QASMBench outcomes are used; report generation is not another scientific run.
