# Number of retrieved examples

`k_1/` and `k_10/` hold the one- and ten-example extensions, launched by `../llm_rag_1_esempio.py` and `../llm_rag_10_esempi.py`. `confronto_k_1_5_10/` analyzes them with the original five-example run. `verifiche_sviluppo/` records software checks.

The extensions retain the 396 train examples, 49 features, train-derived scaling and exact Manhattan retrieval. They were added after the same 90 Test circuits had been examined, so they are exploratory analyses of example count rather than a fresh unseen-data confirmation or retrospective main-configuration selection.
