# Manhattan, WL and WL-summary comparison

`confronto_manhattan_wl.pdf` and `.tex` present the three methods on the same 90 Test circuits with five examples. WL depth h=24 was selected on 88 validation circuits before these WL Test runs.

`genera_report.py` reconstructs measures and checks sources; `impaginazione.py` generates LaTeX; `dati.json` and `tabelle/circuiti.csv` contain all 270 outcomes and paired comparisons. `provenienza.json`, `verifica_report.py` and `verifica_report.json` record checks; `controllo_visivo/` stores rendered pages. This analysis reads saved outcomes and does not select a new main configuration.
