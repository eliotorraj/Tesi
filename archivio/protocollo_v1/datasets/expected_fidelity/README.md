# Dataset delle prime prove

Questa cartella conserva circuiti e risultati della fase precedente alla v2.
Per il Dataset corrente usare la [guida attuale](../../../../datasets/README.md).

| File o gruppo | Funzione |
| --- | --- |
| `full/split_manifest.json` | Partizione originale dei 600 circuiti, tuttora verificata dalla v2. |
| `full/circuits/` | Sorgenti QASM originali; non spostarli o riscriverli. |
| `full/<dispositivo>/` | Risultati storici per dispositivo. |
| `pilot/` | Prova ridotta con circuiti, risultati e confronti. |
| `reports/`, `*.csv`, `*.json`, `*.jsonl` | Registri e resoconti generati dalle prove di allora. |

Il precedente documento descrittivo è conservato nel
[resoconto del Dataset v1](../../../../docs/resoconti/dataset_qiskit_v1.md).
Contiene versioni e comandi storici. Il solo protocollo operativo corrente è
[docs/protocollo_sperimentale.md](../../../../docs/protocollo_sperimentale.md).

L'accessibilità dei circuiti test originali non autorizza la loro valutazione:
restano valide le condizioni di apertura del protocollo.
