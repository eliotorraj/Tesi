# Reproduction toolkit separation: October 1, 2026

This directory documents the separation of the standalone `riproducibilita/` toolkit. `verifiche.json` summarizes its verification.

The toolkit copied and adapted reusable components without creating runtime imports from the archive or prototype. The recorded integration exercise used small real Qiskit compilations and simulated LLM candidates; it is software verification, not a repeated scientific campaign.
