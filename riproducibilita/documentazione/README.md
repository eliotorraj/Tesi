# Documentazione della riproduzione

1. [Guida](guida.md): preparazione e comandi nell'ordine di esecuzione.
2. [Condizioni](condizioni.md): ciò che viene ripetuto, differenze, limiti ed evidenze.
3. [Mappa](mappa.md): ingressi, responsabilità e output.

Il protocollo scientifico corrente resta `prototipo/docs/protocollo_sperimentale.md`. La guida di questa area traduce le fasi in un'esecuzione configurabile, dichiarandone le differenze operative. Non sostituisce retroattivamente i contratti degli esperimenti conclusi.
