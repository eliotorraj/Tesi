## Dove scrivere una nuova informazione

- **Che cosa fa una cartella:** aggiornare il suo README, con parole semplici.
- **Come si usa un componente nei dettagli:** aggiornare la sua guida negli approfondimenti.
- **Che cosa è stato provato e perché:** aggiungere un resoconto datato, collegato dall'indice.
- **Una regola dell'esperimento:** aggiornare il protocollo, conservando la provenienza del cambiamento.
- **Risultati di una prova:** conservare dati originali e resoconti generati nella relativa cartella degli artefatti; collegarli dall'indice dei resoconti.

Lo stato sintetico corrente si aggiorna nel README principale. I resoconti datati
descrivono il momento in cui furono scritti e non vanno riscritti per farli
sembrare attuali. Una piccola modifica può essere aggiunta a un resoconto della
stessa attività: non serve un nuovo README per ogni modifica.

I README dei dati descrivono anche gruppi ripetitivi di file. Non si aggiungono
file a ogni esecuzione, copia congelata o cartella di circuiti.
